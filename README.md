# Numerical Integration Calculator

A single-file HTML web app that computes definite integrals numerically. Enter a function f(x), the lower and upper limits and the number of subintervals, and the app evaluates the integral with the method you choose.

## Methods

- Trapezoidal Rule
- Simpson's 1/3 Rule
- Simpson's 3/8 Rule
- Combined Simpson's (automatic split)
- Auto mode: picks the best Simpson or Trapezoidal result

## Usage

Open `index.html` in any browser, or visit the live demo. No installation or server needed.

Live demo: https://mm9036922-gif.github.io/numerical-integration-calculator/
